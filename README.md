# Lesson 23 · A new house — Interactive Workbook

单文件互动英语练习册（Lesson 23: *A new house*）。打开即用，无需安装、无需联网加载外部资源。

**在线地址：** https://rewqasd.github.io/lesson23-workbook/

## 内容

7 个标签页，覆盖「看—学—练—写」完整闭环：

| 标签 | 内容 |
|---|---|
| Overview | 学习快照、六站路线图、故事时间线、核心问题 |
| Vocabulary | 主题词汇、翻转卡片、词义配对 |
| Grammar | 三个时态工具、时间介词、同形词辨析 |
| Text | 课文《A new house》分段阅读 + 时间轴 |
| Pronunciation | 跟读、重音与连读提示 |
| Practice | 即时判分练习（选择/填空/排序） |
| Writing | 写作工作台（句型脚手架 + 自评清单） |

## 技术说明

- 单个 `index.html`（约 200 KB），CSS/JS/SVG 全部内联，字体走系统字体栈
- 无外部请求、无第三方脚本、无追踪；可离线双击打开
- 响应式布局，手机/平板/桌面均可读

## 本地使用

```bash
git clone https://github.com/rewqasd/lesson23-workbook.git
open index.html   # macOS；Linux 用 xdg-open
```
